# 📝 Signup Page

A modern and responsive **Signup Page** built using **HTML5** and **CSS3**. This project features a clean split-screen layout with an illustration on the left and a user-friendly signup form on the right. It is designed to practice HTML forms, Flexbox, and CSS styling.

---

## 📌 Features

- Responsive two-column layout
- Attractive signup form design
- User illustration section
- Name, Password, and Email input fields
- Stylish Signup button
- Login link for existing users
- Clean and modern user interface
- Beginner-friendly project

---

## 🛠️ Tech Stack

- HTML5
- CSS3
