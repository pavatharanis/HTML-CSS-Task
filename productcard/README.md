# 🎧 Product Card

A simple and responsive Product Card webpage built using HTML and CSS. This project showcases a product with an image, title, description, price, and a call-to-action button in a clean card layout.

## ✨ Features

- Responsive product card design
- Clean and modern UI
- Product image display
- Product name and description
- Price section
- Stylish "Buy Now" button
- CSS hover effects

## 🛠️ Tech Stack

- HTML5
- CSS3
